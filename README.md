# Actividad 2
-Git: Es un programa y sistema de control de versiones que registra cambios en el texto o código sin alterar las demás versiones.

-Github: Es un sitio web en la nube donde guardas tus trabajos y tienes la oportunidad de trabajar con otras personas.

-Repositorio: Es como una carpeta digital o en la nube que almacena archivos, códigos y versiones de un proyecto.

-Commit: Este es un botón de guardado que guarda todo tu proceso del momento  y además de eso te da una nota breve de lo que cambiaste para poder ver  tu progreso o por si te confundiste en algo y arreglarlo.

-Colaborador: Es un usuario que tiene permisos del propietario del repositorio, quién puede editar, leer y escribir dentro de los archivos del proyecto.

-README: Este es el primer texto que aparece al entrar al sitio web donde  te da una breve descripción de qué trata el programa y como se usa.

**Completen:**

*-GitHub sirve principalmente para almacenar proyectos en la nube y permitir que varias personas trabajen juntas en el mismo código sin arruinar el trabajo.*

*-Un repositorio es una carpeta digital que almacena archivos.*

*-Un commit es un botón de guardado del proceso ya realizado y que ofrece notas sobre lo modificado.*
